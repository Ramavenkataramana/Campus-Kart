# CampusKart - Frontend Web Application

Modern React 19 + Vite + Tailwind CSS frontend for CampusKart (College Student Marketplace).

## Features
- **Sleek Black Theme**: Custom deep dark mode styling with ambient glow effects
- **Floating Effects**: Spring-physics hovering product cards and floating stickers
- **Marketplace Discovery**: Instant search by book title, author, course topic, calculator model
- **Peer Negotiation**: Built-in "Make an Offer" feature for students to propose custom prices
- **Direct Handover**: 1-Click WhatsApp coordinator with pre-filled campus meetup messages
- **Campus Wishlist**: Urgent requests board for exams and project submissions
- **Campus Switcher**: Browse items across Main Campus, Engineering Campus, Medical College, and Hostels

## Setup & Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server (Port 3000)
npm run dev

# 3. Build for production
npm run build
```
The frontend automatically proxies `/api/*` to the backend running at `http://localhost:5000`.
